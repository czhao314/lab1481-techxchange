Summary
IBM TechXchange 2026 — Lab 1481

Build AI-Powered Staff Schedules with Planning Analytics, CPLEX, and IBM Bob

In this lab you will take on the role of a hospital unit budget manager. Starting from live Planning Analytics data, you will use IBM Bob to build, solve, and deploy a CPLEX optimization model that simultaneously decides which new hires to activate, which shift to assign each clinician, and what merit raise to award — all within a $1.65M budget cap. No prior knowledge of mathematical programming is required.

I'm building a staffing optimizer for a hospital unit. I know our business rules

My employee and new hire tables and our budget constants are already loaded. A
staffing plan is three sets of decisions:
  - which of the open new hire slots we fill
  - whether each existing employee works Day or Night
  - what merit raise each existing employee gets, from 0% up to 10%

I want a few reusable tools I can use to evaluate any plan, whether it comes from a

  - clinical coverage (weight 1): each person's skill × years of seniority × FTE,
    including new hires, who count as 1 year of seniority and full-time

    scaled by their skill, seniority and FTE
  - shift satisfaction (weight 0.05): people working the shift they prefer

Third, a way to calculate what a plan costs per year:

violated. The rules are:
  - everyone works exactly one shift
  - Day and Night each stay within their minimum and maximum FTE. New hires work Day

  - each shift has at least one senior clinician (skill 4 or higher). A new hire with
    skill 4 or higher counts toward Day.
  - total cost stays under the budget
  - total raises (raise % × base salary) stay under the merit pool
  - no individual raise is above 10%
  - no more than 4 new hires

Print a confirmation when everything is ready.

Running your Optimization model in Planning Analytics

Set up and run the deployed CPLEX endpoint directly from Planning Analytics — creating a Workbench process, a Book with an action button, and an Exploration view to visualize your optimized results.

5.1 — Setup a deployment execution script through Planning Analytics Workbench

5.1.1 — Create a new workbench

  1. From the Planning Analytics Home Page, click the hamburger menu, then click New, then Workbench.
  2. Save your new workbench by clicking the Save icon, then clicking Save Workbench As. In the Save Workbench window, find the Shared tab and click into the HR_Optimization shared folder. In the Name box, enter HR_Opt_Workbench_[YourFirstNameYourLastName], then click Save.

5.1.2 — Create a new process in your workbench

  1. Click the New Process button.
  2. Under Database, find and select HR_Optimization. Set the Process Name to HR_Optimization_Process_[YourFirstNameYourLastName], then click Create.

5.1.3 — Create the deployment execution script

  1. Click the Script tab in the new Process.
  2. Open workbench_script.txt from your lab workspace folder. Copy the entire contents and paste them under #Section Prolog in the Script tab.
  3. Fill in the one remaining value at the top of the script — sDeploymentID = '';. Use the DEPLOYMENT_ID printed in your step_4_bob.ipynb Cell 4 output when you ran Prompt 4.3 — Create the live batch deployment endpoint. All other credentials are already pre-populated in the script.
    If you haven't run the Deploy section yet, complete section 3 (Deploy and Test the Model) first, then return here with your DEPLOYMENT_ID.
  4. Save the script by clicking the Save icon, then selecting Save as.
  5. In the Save As dialog, set the Process Name to RunStaffOptimization_[YourFirstNameYourLastName], then click Save as.
  6. Select the Parameters tab and click Add parameter +. Add one parameter:
    1. Parameter name: pVersion
    2. Type: String
    3. Value: YourFirstNameYourLastName

5.1.4 — Test the deployment script

  1. Click Run in the process toolbar.
  2. In the popup window that appears, confirm pVersion shows your name, then click Run.

5.2 — Create and configure the Planning Analytics Book

  1. Click the hamburger menu, then New, then Book.
  2. Click the Save icon, then click the Shared tab, then select the HR_Optimization folder. In the Name field type HR_Opt_Book_[FirstNameLastName], then click Save.
  3. With the book open, open the book spec editor using the keyboard shortcut:
    Windows Ctrl + Q , then /
    Mac ⌘ + Q , then /
  4. Open the dashboard.json file provided in the lab files, copy its entire contents, paste it into the spec editor window, then click the blue Update button. The book will reload with all tabs, widgets, and the Run Optimization button already configured.
    Note: Make sure you replace all existing content in the spec editor before clicking Update — do not append.
  5. Navigate to the Run Optimization tab. You will see the blue Run Optimization button and a results grid below it.
  6. Click the Run Optimization button once to select it, then click Properties in the upper-right corner, then open the Configure tab. Verify that Run Process is toggled ON (green) and that the following are set:
    1. Database: HR_Optimization
    2. Process: RunStaffOptimization_[YourFirstNameYourLastName]
    3. The Refresh after execution checkbox is checked
    If any of these are missing, set them now, then click the Save icon.

5.3 — Run the optimization and review your results

  1. Toggle Edit to OFF using the toggle in the top-left of the Book toolbar.
  2. On the Run Optimization tab, click the blue Run Optimization button. The job will take 60–90 seconds. The results grid will refresh automatically when it completes — you should see your name row populated with Total Workforce Cost Used, Merit Pool Used, and Budget Remaining.

  5. Click the Schedule tab. Review each of the 12 clinicians' band assignments (Day vs Night), their FTE, and their annual loaded cost. Notice that 11 of 12 employees were assigned to their preferred shift.
  6. Click the Merit & Retention tab. Review the merit percentage and dollar amount awarded to each employee. Notice that merit is not purely risk-ranked — the optimizer maximises retention ROI across the combination of attrition risk, skill score, seniority, and FTE.
